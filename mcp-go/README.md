# Varwin 18 Full MCP Server (Golang Edition) 🚀

Полноценный, 100% функциональный сервер **Model Context Protocol (MCP)** на **Go** для платформы **Varwin 18 XRMS**.

---

## ⚡ Особенности реализации

- **100% охват платформы**: 27 готовых инструментов + универсальный GraphQL-исполнитель `varwin_graphql_raw`, дающий доступ ко всем 28 запросам и 71 мутации Varwin 18.
- **Единый бинарник**: 7.0 МБ без внешних зависимостей (`bin/varwin-mcp`).
- **Сверхбыстрый отклик**: время обработки запросов **~5–20 мс**.
- **Двусторонняя синхронизация**: чтение и запись Python-кода и визуальной логики Blockly.
- **Встроенная защита рантайма**: валидация синтаксиса и ограничений Unity/Varwin (запрет блокировок потока, `time.sleep`, `asyncio`, проверка `AddStart/AddUpdate`).

---

## 🛠️ Полная таблица инструментов (27 MCP Tools)

### 1. Ядро и системная интроспекция
| Инструмент | Назначение |
|---|---|
| `varwin_status` | Статус сервера (URL, версия платформы, активный Workspace ID, статус токена) |
| `varwin_graphql_raw` | **Универсальный GraphQL-терминал**: выполнение любого сырого GraphQL-запроса или мутации с переменными и авторизацией |
| `varwin_get_system_module` | Получение полного системного рантайм-модуля `Varwin.py` с типами и сигнатурами прямо из движка |

### 2. Управление проектами
| Инструмент | Назначение |
|---|---|
| `varwin_list_projects` | Список всех проектов с метаданными, сценами и флагами Mobile/Multiplayer |
| `varwin_get_project` | Подробная информация о проекте (ID, GUID, автор, сцены) |
| `varwin_create_project` | Создание нового проекта в воркспейсе |
| `varwin_rename_project` | Переименование проекта по ID |
| `varwin_duplicate_project` | Клонирование/дублирование проекта |
| `varwin_delete_project` | Удаление проекта по ID |

### 3. Сцены и 3D-окружения (Environments)
| Инструмент | Назначение |
|---|---|
| `varwin_get_scene` | Полная структура сцены, SID, список 3D-объектов и модулей кода |
| `varwin_create_scene` | Создание новой сцены в проекте на основе шаблона окружения |
| `varwin_rename_scene` | Переименование сцены |
| `varwin_duplicate_scene` | Клонирование сцены в тот же или другой проект |
| `varwin_delete_scene` | Удаление сцены по ID |
| `varwin_list_scene_templates` | Список доступных локаций/окружений (Sci-Fi, Лес, Дом, Таунхаус, Пустая сцена) |

### 4. 3D-объекты и библиотека
| Инструмент | Назначение |
|---|---|
| `varwin_list_scene_objects` | Все 3D-объекты сцены с именами Python-переменных и типами обёрток |
| `varwin_list_library_objects` | Каталог доступных 3D-объектов библиотеки Varwin (50+ объектов) с поиском |
| `varwin_update_scene_objects` | Расстановка и обновление 3D-объектов сцены (координаты, повороты, свойства) |

### 5. Логика, Python и Blockly
| Инструмент | Назначение |
|---|---|
| `varwin_get_code_modules` | Исходный код Python-скриптов сцены (`Main.py` и модули) |
| `varwin_update_code_modules`| Сохранение Python-скриптов с автовалидацией перед отправкой |
| `varwin_validate_python` | AST-линтинг кода под требования игрового цикла Varwin |
| `varwin_get_blockly` | Просмотр сгенерированного кода и структуры блоков Blockly |
| `varwin_update_blockly` | Обновление визуальной логики Blockly на сцене |

### 6. Ресурсы и медиа
| Инструмент | Назначение |
|---|---|
| `varwin_list_resources` | Список загруженных текстур, моделей, звуков и видеоматериалов проекта |

### 7. Справочник API и поиск
| Инструмент | Назначение |
|---|---|
| `varwin_search_api` | Полнотекстовый поиск методов, поведений и событий по документации |
| `varwin_get_wrapper_doc` | Детальная справка по конкретной обёртке (например `VBotBoyWrapper`, `Light`) |

### 8. Рruntime и 3D-клиент
| Инструмент | Назначение |
|---|---|
| `varwin_launch_client` | Запуск сцены в 3D Unity-клиенте Varwin (режимы Desktop / VR) |

## 🔨 Сборка

```bash
./scripts/build_mcp_go.sh
```

Бинарник компилируется в `bin/varwin-mcp`.

---

## 🔌 Конфигурация в Antigravity

В `~/.gemini/config/mcp_config.json`:

```json
{
  "mcpServers": {
    "varwin": {
      "command": "/home/reg/Projects/NOVAT.varwin/bin/varwin-mcp",
      "args": [],
      "env": {
        "VARWIN_URL": "http://127.0.0.1:1801"
      }
    }
  }
}
```
